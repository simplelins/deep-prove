# 设计 · D1.1 带状注意力分数（SWA 的 trace 级实现，M1/D1.1）

> 目标：把 gemma/llama 注意力的 score 张量从 `[Hq,s,s]` 缩到 `[Hq,s,w]`（w=滑窗），
> 使 s=32k 的 trace 从 TB 级回到可证明量级（L 文档 /50 论证的落地）。
> **关键发现**：`attention_mask/prove.rs` 的 Local span 证明已实现带状结构的稀疏
> 分解证明技术（U·S+P 分解、`fix_lower_mle_columns`、shift 矩阵 β 循环求值，
> 不物化全矩阵）——本设计把同一技术应用到 **score 计算**，属工程设计非原创研究。

## 1 现状与差距

| 环节 | 现状 | 差距 |
| --- | --- | --- |
| 推理/trace | QK einsum 产出全量 `[Hq,s,s]`，SWA 以 `triu_mask` 掩码（`evaluate.rs:35-70`） | **分数张量本身不缩**——s² trace 仍在（s=32k 即 43TB Fr，不可行） |
| mask 证明 | Local span 的 offset 矩阵 O=U·S+P 稀疏分解证明 ✓ | 可直接复用 |
| softmax/AV | 在全量 score 上 | 缩到 `[Hq,s,w]` 后算子不变、张量变小 ✓ |

## 2 带状 QK 算子（新图算子 `BandedQK`）

**语义**（等价于全量 QK+SWA 掩码的窗口内取值）：

```
B[h, i, off] = Σ_d Q[h, i, d] · K[h, j(i,off), d],   off ∈ [0, w)
j(i,off) = clamp(i - (w-1) + off, 0, s-1)             ← 左边界 clamp（因果+滑窗）
```

- 输出张量 `[Hq, s, w]`（w=512 时 s=32k 的 score 体积 /64）；
- `j(i,off)` 的耦合（i 与 off 的加法 + clamp）是非平凡索引——**这正是需要证明的部分**。

## 3 证明方案（复用 mask 层的稀疏分解词汇）

引入"移位 K"中间张量 **K′[h, i, off, d] = K[h, j(i,off), d]**，则 B 是标准 einsum：

```
B[h,i,off] = Σ_d Q[h,i,d] · K′[h,i,off,d]        （普通 einsum，证明机制现成）
```

K′ 的证明 = gather 关系的证明。按 mask 层的分解词汇：

```
K′ = Σ_{δ∈[0,w)} S_δ · K_δ        （每 δ：S_δ[i,off]=1 iff j(i,off)=i-w+1+δ；K_δ=K 沿 i 轴移位 δ）
```

- `S_δ` 是每行恰一个 1 的**移位矩阵**（mask 层已证明过同款：`fixed_shift_mle` 的
  β 循环求值，`prove.rs:151-166`）；
- `K_δ`（K 沿 i 轴的环形移位）的 MLE 求值 = 对 K 的 MLE 做索引位的线性坐标变换——
  加法移位在 MLE 坐标上是**关于 i 位的仿射置换**，其 eq 结构可解析展开
  （与 `fix_lower_mle_columns` 同族技巧）；
- K′ **不物化**：sumcheck 的虚拟多项式直接以 `Σ_δ S_δ·K_δ` 的分解式参与
  （VirtualPolynomialsBuilder 支持表达式项），证明成本 = w 个稀疏移位项的
  O(s·w) 而非 O(s·s)。

**成本核算**（s=32k, w=512, d=2560, Hq=40）：

| 项 | 全注意力 | 带状 |
| --- | ---: | ---: |
| score 体积/层 | 40·32k² = 43G elem | 40·32k·512 = **0.67G elem（/64）** |
| B 的 sumcheck | — | O(s·w·d) 求值读 Q/K′ 分解项 |
| K′ 分解项求值 | — | O(w·s)（每 δ 的移位 eq 解析式） |
| 全模型 trace | 67.4TB Fr | **≈3.5TB Fr**（L 文档口径一致） |

## 5 风险与开放问题

1. **K_δ 移位 MLE 的解析 eq**：环形移位在 MLE 坐标上的展开是本设计的技术核心，
   需先写数值小样（w=2, s=8）与 dense 基线对拍；
2. **V 侧复用**：AV 的 K′ 分解与 B 共享可省一次分解求值，但引入跨算子的
   claim/point 耦合——先做不共享版，共享作为后续优化；
3. **左边界 clamp**：`j<0` 的项归零（Q 仍被读）——分解式中体现为 S_δ 的行覆盖
   不完整（mask 层的 P 矩阵同款处理）；
4. **llama-2 无原生 SWA**：Gemma-3 系先行（span 已在 config）；llama 系按
   L 文档建议在协议层加窗（推理数值会变——需单独确认）。

## 8 附录：B sumcheck 的精确 spec（11-10，实现用）

**为什么不能用 einsum 的 fix_axes 模式**：einsum 的证明 = 输出 claim 点按 (i,j) 组拆分、
按组固定 Q/K、只对收缩轴 d 跑 sumcheck（`einsum/prove.rs:144-184`，`mapping.fix_axes`）。
BandedQK 的 K 侧索引 j(i,off) 与 i、off **两个变量组耦合**（非线性索引），无法按组固定。

**自定义 sumcheck spec**（变量顺序 off → i → d）：

```
目标恒等式（对任意点 (x_h, x_i, x_off, x_d)）：
B(x) = Σ_{i,off,d} eq_i(x_i)·eq_off(x_off)·eq_d(x_d)·Q(h,i,d)·K(h, j(i,off), d)
j(i,off) = i-(w-1)+off（clamp 到 [0,s)）

维护不变量：每轮维护"移位 K 的线性组合"M = Σ_δ c_δ·K_δ，
K_δ[i,d] = K[h, clamp(i-δ), d]（δ 为整数移位量），
c_δ = Σ_{off: off-w+1=-δ mod 语义} eq_off 的部分绑定值。
```

- **off 轮**（w 的 log₂w 位）：每绑一位，δ 的候选按位分裂，c_δ 更新；
  M = Σ_δ c_δ·K_δ 在剩余 (i,d) cube 上重建（O(s·d)/轮——张量级，可承受）；
  off 耗尽后 c 收敛为单点 δ*（M = K_{δ*}）。
- **i 轮**：mask 层同款技巧（`fixed_shift_mle` 的 β 循环，`attention_mask/prove.rs:151-166`）
  对 K_{δ*} 逐位折叠；Q 同轮标准折叠。
- **d 轮**：标准。
- **终点**：Q 与 K 在终点的 eval → 变为对 Q/K 承诺的 claim（接入现有 claim 链与
  PCS 批量 opening）。
- **verifier 镜像**：同样的轮结构，挑战从 transcript 逐轮采样；K 侧以解析式
  （β 循环 + c_δ 系数）重算每轮消息一致性——零物化。

**边界 clamp**：S_δ 的行覆盖不完整（j<0 段）→ c_δ 权重乘以 mask 层 P 矩阵同款的
覆盖指示（等价于把 j<0 的项置 0——与 evaluate 的 zero-pad 一致）。

**验证路径**：先实现 dense 基线单测（K_δ 物化版 vs 全量 QKᵀ 切窗）验证 sumcheck
数学，再切换到 β 循环零物化版对拍，最后接入图。

## 9 ⚠️ 研究障碍记录（11-10，实现中确认）

**带状 gather 的 claim 折叠是研究级问题**（与 A2 同类）：

自定义 sumcheck（off→i→d 轮序）数学成立（dense 版恒等式已验证），但其**终点
evaluation 无法折叠为 committed K 的单点 claim**：field 元素挑战下，gathered-K 的
终值 = Σ_δ c_δ·K_δ(x*)——K 的 MLE 在**多个不同点的求值线性组合**，不是
K(p) = e 形态的单点 claim，无法接入现有 claims batching + PCS opening 链。

已评估的出路：
1. **carry-aware sumcheck / Toeplitz 论证**：j 的比特 = i 比特与 off 比特的带进位
   加法——文献中的 banded/toeplitz matmul 论证正是解这个——研究级；
2. **logUp 重排论证**：K′ = gather(K, f) 以重排/多重集参数证明——f 是闭式映射，
   需新的 lookup-style 构造——研究级；
3. **K′ 物化为 committed trace 张量**：gather 关系仍需证明（同一问题递归），
   且 w·s·d 承诺成本过大——排除。

**结论**：D1.1 的 evaluate（推理）侧已完成 ✓；prove 侧 = 研究项
（banded-matmul/gather argument），与 A2 同属**协议研究轨**。
M1 的"Gemma-1B/32k PASS"门被此阻塞——M1 工程部分（S1/P1/evaluate）可先行交付，
32k 证明门转入研究轨里程碑。

## 10 已采纳方向：方案一（Toeplitz/banded 论证）——数学推演（11-10）

**核心恒等式（差分结构消解耦合）**：band 映射 j-i = off-(w-1) 是**差分**，
指数权重把差分变成比值：

    Σ_{i,off} B[i,off]·z^i·ρ^off = ρ^{w-1}·Σ_{i,j,d} Q[i,d]·K[j,d]·(z/ρ)^i·ρ^j·M[i,j]

其中 M = 因果+带状掩码（U·S+P 同款结构）。**纯 Toeplitz（无因果）时 M≡1、右侧
完全因式分解**：ρ^{w-1}·Q̂(z/ρ)·K̂(ρ)——整个带状积的 aggregate = Q/K 两个
单点求值之积，零 sumcheck ✓。

**因果项的处理（未完成部分）**：j ≤ i 的三角结构不可分（per-axis 权重无法表达
i≥j）→ 右侧带 M 的和不可完全因式分解。可行构造 = mask 层的两段式模式：

1. 主段（U·S 部分，|i-j|<w 且 j≤i）：前缀和 sumcheck（running-sum 技巧，
   `attention_mask/prove.rs` 的 local_mask_proof 同款）——三角结构的
   Σ_{j≤i} 用前缀和折叠，每轮 O(剩余) ；
2. 角部（P 部分，i<w-1 的 j<0 clamp 区）：O(w²) 个位置——直接作为
   附加 claim（点数/体积极小）或并入前缀和；
3. 终点 claim：Q/K 的单点 MLE claim（指数权重的可分性恒等式：
   Σ_i v_i·y^i = Π_k(1+w_k)·v_MLE(x_k=w_k/(1+w_k))，w_k=y^{2^k}）——
   接入现有 claims batching + PCS opening ✓。

**声音性**：Schwartz-Zippel 于 (z, ρ)（+前缀 sumcheck 的轮挑战）——B 在任一
位置错误则加权恒等式失效概率 1/|F| ✓。

**工程量重估（11-10 数值验证后修正）**：纯因式分解已被数值证伪（带状约束
|j-i| ≤ w-1 非乘积集——LHS/RHS 不等的测试现场保留于 `poly_identity.rs` 的
ignored 测试）。正确构造 = **互相关多项式形式 + 截断乘积恒等式 + 商见证**：

- 交叉相关形式：LHS = Σ_Δ ρ^Δ·[z^{-Δ} 系数 of Â_d(z)·B̂_d(z^{-1})]
  （Â_d(z)=Σ_i Q[i,d]·z^i 等——生成多项式形式）；
- 带状截断 = 乘积多项式的窗口部分和 → 需要商见证承诺：T_d·W = P_d - R_d
  （W=窗口多项式，R=余项），在随机点 τ 检查；
- 需要新的 committed 见证多项式（商/余项）——mini-Plonk 式关系，协议 machinery
  超 utility 级别。

**研究轨定位维持**：构造路径已完整 mapped（截断乘积 + 商见证），预估 2-3 天
专注实现 + 验证；数学无未定问题，但工程量与风险需按协议开发对待。

## 11 Stage A 最终实现蓝图（11-10，logUp 接线 spec）

**框架确认**：`LogUpInput` 原生支持多列 tuple 绑定（`column_evals` 多列 +
`constant_challenge`/`column_separation_challenge` 分离挑战）——gather 的动态表
**直接装入现有 GKR 接口**，无需任何协议新构造。

### GatherRows 证明结构（全部既有机制）

```
Table 侧 LogUpInput::Table {
  column_evals: [K[:,0], K[:,1], ..., K[:,dk-1], IndexJ(0..s)],  // K 列 + 索引列
  multiplicities: f 直方图（闭式，数据无关）,
  挑战: challenge_storage 派生（gather 注册为 pseudo-table 或 transcript 采样）
}
Lookup 侧 LogUpInput::Lookup {
  column_evals: [K'[:,0], ..., K'[:,dk-1], F(t)(0..s·w)],        // K' 列 + f 索引列
  columns_per_instance: dk + 1,
}
```

γ-binding（多列 × 分离挑战）使 (索引, 值) 对成为原子——GKR 证明两侧 tuple 多重集
相等 ⟹ K' = gather(K, f) 位置精确 ✓。索引列/重数为**公开常量**（数据无关）——
verifier 解析重算，无需承诺。

## 12 Claims 接线发现（11-10，集成实现中确认）

### 12.1 Claim 点构造

logup 点覆盖 t 变量；flattened K' poly（[s·w, dk] 行主序展平，d 为低位变量）的
d 变量绑定为**基向量 e_d**——logup 的 per-column claims（d 列在 t 点的求值）
映射为 flattened poly 在 (logup_point ++ e_d) 的 claims：

    claim_d = Claim(point = logup_point ++ e_d, eval = logup_output_claims[d])

### 12.2 add_witness_claim 语义

`add_witness_claim(id, vec![vec![c1..ck]])`：外层 = poly 序、内层 = 该 poly 的
claims——gather 为单 poly（K' 展平 MLE）+ dk 个 claims。注意
`add_witness_claim_per_poly` 会把每个 claim 映射为独立 poly（ensure
comms.len() == claims.len() 不匹配）——多 claim 单 poly 必须用 add_witness_claim。

### 12.3 ProvableOp 集成模式

`GatherRows<Element>: ProvableOp<F, PCS>`（Ctx = GatherRowsCtx）+ OpInfo/PadOp/
ProveInfo for GatherRows<Element>；Layer/LayerCtx 分发臂照 AttentionMask 模式；
`Element: TensorTypeParam<Kind = ...>` 的关联 Kind 约束需要按 T::Kind 泛型处理
（避免具体 Fp 类型绑定）。

### 12.4 声音性补充论证

多集等 + γ-binding 的位置精确性：f(t)=j 的所有位置正确值均为 K[j]（同值组），
组内置换不改变任何位——多集等 ⟹ 位置精确 ✓（clamp 重复组同理）。
