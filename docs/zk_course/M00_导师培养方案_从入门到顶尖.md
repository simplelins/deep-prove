# M00 · 导师培养方案：从入门到行业顶尖

> 这是大师篇的总纲。回答一个问题：**一个 ZK 领域的顶级导师，会怎样展开教学，才能把学生带到"行业顶尖大牛"的水准？**
> 前提盘点：学生已完成（或正在完成）基础篇 S01–S06、提高篇 S07–S10、论文精读 S11。这套课程把学生带到了哪里、还差什么、怎么补——本方案全部说清。

---

## 1. 先定义终点："行业顶尖"的五级阶梯

"精通 ZK"是句空话，顶尖必须拆成**可检验的等级**。每一级都有明确的过关物，导师据此判断是否放行：

| 级别 | 能力定义 | 过关物（可检验） | 课程落点 |
| --- | --- | --- | --- |
| **L1 会算** | 任何协议都能在纸面跑通小例子，每个中间数可复核 | mod-13 手跑 sumcheck / KZG 打开 / LogUp 折叠，零算错 | S01–S06、S07–S09 |
| **L2 会证** | 白板证明完备性/健全性；会给一个系统做"健全性预算表" | 10 分钟白板：sumcheck RBR 论证、三点恒等式、LogUp 恒等式 | S06 §5、S08 §4 |
| **L3 会读** | 新论文 1 小时抽出协议骨架；任何实现 30 分钟定位关键路径 | S11 式的逐节伴读报告；prove_chunk 盲测定位 | S11、L07 |
| **L4 会造** | 从论文到生产级实现（对拍/fuzz/上游 PR）；为给定负载设计完整协议栈 | P11 期末项目被合并；M08 顶石设计通过评审 | M07、M08 |
| **L5 会评/会创** | 批判性评估（找出论文的隐含假设与薄弱环节）；提出改进并用实验验证；观点被同行引用 | 协议审计报告（含攻击）；ePrint 短文或开源工具 | M06 + 研究循环 |

**顶尖大牛的日常标志**（面试/评审现场可检验）：给一个陌生工作负载，30 分钟内给出系统选型并量化理由；被同行挑战时能当场推导，而不是引用权威。**L4 之前靠课程，L4→L5 靠实战循环**——这是导师方案的核心结构。

## 2. 导师的六个教学动作（怎么教才到得了 L4/L5）

1. **苏格拉底链**：每个新概念，导师先连问三个问题再开讲（"验证方为什么不能自己算这个？""如果不承诺会发生什么？""这个步骤去掉会破坏哪条性质？"）。现有 S 课的"先做后名"就是它的书面化。
2. **先做后名**：已在 S 课执行；M 阶段升级为"**先实现后读论文**"——M02 让学生先手跑 mini-FRI，再去读 FRI 原文。
3. **费曼回讲**：W3/W6/W12 三个检查点，学生 10 分钟白板讲透一个证明，导师只追问不提示。讲不清 = 回炉。
4. **失败解剖**：导师**故意**给出有漏洞的协议变体（如去掉 batched sumcheck 的 γ 随机性、eq 表预先合并），学生必须找到攻击。L4/L5 的核心训练。
5. **数字强迫症**：任何主张必须配可复算数据。本课程 v1.1 审计（域常数错、健全性口径错）就是示范——大牛的第一反射是"这个数从哪来"。
6. **真实战场**：L4/L5 不接受玩具闭环——对拍要对着仓库 CPU golden、PR 要提给真实上游、评审要模拟 ePrint 的匿名恶评。

## 3. 缺口诊断：S01–S11 之后还差什么

| 能力维度 | S 课已覆盖 | 顶尖要求的缺口 | 对应模块 |
| --- | --- | --- | --- |
| IOP 原语 | sumcheck/GKR 式/LogUp-GKR（一个家族的深度） | 看见**整个 IOP 设计空间**的广度 | M01 |
| 承诺方案 | KZG/HyperKZG（配对族） | **哈希族**（FRI/BaseFold/WHIR/Binius）与**内积族**；选型判断 | M02 |
| 数域 | BN254 Fr 一个域 | 小域（Goldilocks/M31/二进制塔）为何主导新一代系统 | M03 |
| 查表 | LogUp-GKR 一个点 | Plookup→Caulk→cq→Baloo→Lasso/Jolt 谱系与取舍 | M04 |
| 折叠/递归 | 无 | Nova 一族；folding×sumcheck 混合；IVC/聚合 | M05 |
| 安全 | 健全性直觉 | FS 的 ROM 现状、grinding 攻击、健全性预算表、审计清单 | M06 |
| 工程闭环 | 对拍工具、算子规格 | 从论文到上游 PR 的完整方法论 | M07 |
| 设计 | 一个系统的架构 | 给陌生负载做全套设计并答辩 | M08 |

**结论**：S 课是"L1–L3 的最佳路径"，但单靠它会产出"DeepProve 专家"而非"ZK 大牛"。大师阶段 = M-track 八模块 + 研究循环。

## 4. M-track 大纲（每模块：目标 / 内容 / 动手 / 过关）

| 模块 | 目标（一句话） | 动手任务 | 过关标准 |
| --- | --- | --- | --- |
| **M01 设计空间总图** ✅ | 脑里有"算术化 × PCS × 查表 × 折叠"四轴地图，能做选型 | 给 4 个工作负载做选型辩护 | 导师扮演恶意评审，挑不出论证漏洞 |
| **M02 FRI 与哈希承诺** ✅ | 手跑 mini-FRI；讲清 BaseFold/WHIR/Binius 与 KZG 族的硬取舍 | mod-13 mini-FRI 全程 + Rust 版 | 三点抽查攻击实验 + 与论文对拍 |
| **M03 数域的选择学** | 为什么 Goldilocks/M31/二进制塔统治新系统；2-adicity 与 FFT 的关系；BN254 的取舍 | 在 mod-13 框架下推导"小域的代价"（位宽不足→扩展域） | 选型报告：给 3 种工作负载配域 |
| **M04 查表论证全景** | Plookup→Lasso/Jolt 谱系；LogUp-GKR 的坐标 | 实现 Plookup toy 并与 LogUp toy 对比证明大小 | 复杂度对比表（承诺/证明/验证三维） |
| **M05 折叠与递归** | Nova 的 relaxed R1CS 折叠直觉；folding×sumcheck 混合；IVC/聚合的区别 | 手推 Nova 对 2 约束电路的一步折叠 | 给"流式证明长视频"设计折叠方案 |
| **M06 安全与攻击者视角** | FS 的 ROM 证明现状；grinding；健全性预算表；审计方法 | 攻击一个被故意弱化的协议（导师提供） | 审计报告：列出攻击面 + 修复建议 |
| **M07 从论文到代码** | 论文→claim 卡片→最小实现→fuzz 对拍→上游 PR | 把 S11 精读的协议之一实现并提 PR | PR 被合并或收到实质性 review |
| **M08 顶石设计** | 给陌生负载（EVM 块 / 70B 模型 / 隐私交易）做全套设计 | 15 页设计文档 + 30 分钟答辩 | 三位"模拟评审"（导师出恶评）通过 |

**排期**：M01/M02 本次已交付；M03–M06 按批续写（每批 2 讲，同风格：先做后名 + mod-13 贯穿 + 数字可复算）；M07/M08 是实践模块，讲义只提供方法论与模板。

## 5. 大师阶段节奏（W13–W24，第二学期）

| 周 | 内容 | 产出 |
| --- | --- | --- |
| W13–W14 | M01 地图 + M02 FRI | 选型辩护 1 + mini-FRI |
| W15–W16 | M03 数域 + M04 查表全景 | 选型报告 2 + Plookup toy |
| W17–W18 | M05 折叠 | Nova 一步手推 + 折叠设计 |
| W19–W20 | M06 安全 | 攻击实验 + 审计报告 |
| W21–W22 | M07 论文→代码 | 上游 PR |
| W23–W24 | M08 顶石 | 设计文档 + 毕业大答辩（三位模拟评审） |

与研究循环并行（每周固定 4 小时）：ePrint 每周筛读 1 篇（L09 §3 方法论）→ 每月一篇精读笔记 → 每季度一个开源贡献。**L5 不是课程能教的，是循环里长出来的**——导师的职责是保证循环不断。

## 6. 出师标准（毕业大答辩的评分表）

| 关卡 | 形式 | 及格线 |
| --- | --- | --- |
| 白板关 | 抽签复述任一核心证明（sumcheck RBR / 三点 / LogUp / Nova 折叠） | 无逻辑跳跃，能应答两层追问 |
| 实现关 | P2/P5/P7/P11 的代码现场改需求 | 30 分钟内改对且对拍仍绿 |
| 设计关 | M08 设计文档答辩 | 选型有量化依据；对"为什么不选 X"有答案 |
| 评审关 | 导师出示一篇真实 ePrint 论文 | 60 分钟内产出 claim 卡片 + 两个质疑 |

**四关全过 = 出师**。此后学生与导师的关系从"教学"变为"同行"——一起读论文、互评设计、共挑协议毛病。

## 7. 导师的三条底线

1. **诚实优先于权威**：讲义错了就承认并修（v1→v2、v1.1 审计都是先例）；学生发现错误同等感谢；
2. **一切可复算**：没有源码行号或推导的数字不进讲义；
3. **不装懂**：超出确认范围的内容明确标注边界（如 S11 对附录 B 的处理），并给学生的自查路径。
