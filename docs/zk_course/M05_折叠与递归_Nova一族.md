# M05 · 折叠与递归：Nova 一族

> 问题：证明"一个跑了 **N 步**的计算"。两条傻路：①把 N 步全部塞进一个电路（N 步 = N 倍门数，proof 系统被撑爆）；②每步证一次、验证方读 N 个证明（违背"短"，S01）。正统的第三条路——**递归**（把"验证上一个证明"做成电路）——又贵得惊人（配对验证器进电路要百万门）。**Nova**（2021）给出了第四条路：**不证旧证明，把旧实例"折叠"进新实例**——一次小线性运算。本讲你在 mod-13 里亲手完成一次 Nova 折叠，并验证它对**任意**挑战成立。

## 1. 先把"实例"写成代数形状

R1CS（M01 轴一的第一方言）把每步计算写成一组约束 `Az ∘ Bz = Cz`（∘ = 逐元素乘；A、B、C 是公开矩阵，z 是"赋值向量" = 公共输入 + witness）。Genuine（诚实）的 z 满足等式。

Nova 的关键改写——**relaxed R1CS**（"放松的"）：

```
Az ∘ Bz  =  u·Cz + E
```

多了一个标量 u 和一个**误差向量 E**。诚实实例是它的特例：u = 1、E = 0。**E 度量"这个实例离真有多远"**——记住这一点，折叠的全部魔法都建立在它上面。

## 2. 玩具：一条约束的 R1CS（mod 13）

最小系统：A = [1]、B = [1]、C = [2]，z 是单个数。约束：**z·z = 2z**（即 z ∈ {0, 2}）。

```
genuine 实例：z₂ = 2（2×2 = 2×2 ✓），u₂ = 1，E₂ = [0]
累积器（relaxed）：z₁ = 4，u₁ = 3，E₁ = [5]
   自检：Az₁∘Bz₁ = 4×4 = 16 ≡ 3；u₁·Cz₁ + E₁ = 3×(2×4) + 5 = 29 ≡ 3 ✓  （mod 13）
```

注意累积器 **不满足真约束**（4×4 = 16 ≠ 2×4 = 8）——它"欠着"一个误差 E，但这个欠账被**代数地记录在案**。这就是"relaxed"的含义：不要求每步都完美，要求**误差可控、可追踪**。

## 3. 折叠：一次线性运算（核心公式）

把累积器 z₁ 与一个**新鲜 genuine 实例** z₂ 用随机挑战 r 折叠：

```
z* = z₁ + r·z₂        u* = u₁ + r·u₂        E* = E₁ + r·T
其中交叉项 T = Az₁∘Bz₂ + Az₂∘Bz₁ − u₁·Cz₂ − u₂·Cz₁
```

**代入玩具**（T 的四个量：Az₁ = 4、Bz₂ = 2、Az₂ = 2、Bz₁ = 4、Cz₂ = 4、Cz₁ = 8）：

```
T = 4×2 + 2×4 − 3×4 − 1×8 = 8 + 8 − 12 − 8 = −4 ≡ 9 (mod 13)
```

**验证折叠正确（对任意 r）**。折叠后要求：z*² = u*·C(z*) + E*。左：

```
z*² = (4 + 2r)² = 16 + 16r + 4r² ≡ 3 + 3r + 4r²   (mod 13)
```

右：

```
u*·C(z*) = (3+r)·(2(4+2r)) = (3+r)(8+4r) = 24 + 12r + 8r + 4r² ≡ 11 + 7r + 4r²
+ E* = [5 + 9r]
合计 = 16 + 16r + 4r² ≡ 3 + 3r + 4r²    ✓✓ 与左边逐系数相等
```

**代 r = 5 落地**：z* = 14 ≡ 1，u* = 8，E* = [50 ≡ 11]；核：z*² = 1，u*Cz* + E* = 8×2 + 11 = 27 ≡ 1 ✓。

**为什么恒等（两行推导，自己补全）**：把 (z₁+rz₂)² 展开 = z₁² + r(z₁z₂+z₂z₁) + r²z₂²，其中交叉项 z₁z₂+z₂z₁ 恰好被 T 吸收——**T 就是"折叠时产生的交叉项"的精确记账**。E* = E₁ + rT 的含义：**旧误差原样保留 + 新交叉项记账**。诚实者折叠后的 E 依然小；不诚实的输入会把误差暴露在 E 里。

## 4. 为什么这就解决了"100 万步"

IVC（增量可验证计算）的新范式：

```
累积器 ←折叠← 新鲜实例₁ ←折叠← 新鲜实例₂ ←折叠← … ←折叠← 新鲜实例_N
```

- 每一步的真实计算（z_{i+1} = step(z_i)）与折叠的交叉项 T **一起**在一个小电路里证明（Nova 的"折叠电路"），挑战 r 由 Fiat–Shamir 从 S05 的 transcript 派生；
- N 步之后：**一个**累积器 + **一个**最终证明。验证方：验最终证明 + 抽查折叠电路链——不读 N 个证明；
- 你在 S06/S08 学的全部机器没有作废：Nova 里证明"折叠电路执行正确"仍然用 sumcheck/PCS——**折叠是外层的调度术，内层还是你熟悉的发动机**。（HyperNova 进一步把折叠推广到 sumcheck 原生的 CCS 关系——folding 与 sumcheck 在合流，这是当前协议设计的前沿方向。）

**与 DeepProve chunking 的对比**（M00 缺口诊断的直接回答）：

| | chunking（DeepProve） | 折叠（Nova 族） |
| --- | --- | --- |
| 结构 | 并行分治，chunk 间承诺绑定 | 串行累积，一步包一步 |
| 验证方 | 逐 chunk 核对（数量 ∝ chunk 数） | 恒定（最终一个证明） |
| 适用 | 单次推理、可并行、内存受限 | 长流式计算（IVC）、持续服务 |
| 证明延迟 | 每 chunk 独立 | 串行链（折叠必须逐步） |

LLM 单次推理选 chunking 是对的；"证明服务运行了 10⁶ 次推理"就该轮到折叠——**同一张地图上的两个坐标，不是谁取代谁**。
