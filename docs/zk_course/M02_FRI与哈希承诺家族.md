# M02 · FRI 与哈希承诺家族

> S07 的承诺有一根刺：**trusted setup**。仪式里那个销毁的 τ，要求你相信"至少一个人是诚实的"；配对还不是抗量子的。新一代系统（STARK/BaseFold/WHIR/Binius）全部押注在另一条路：**哈希承诺**——本讲你先弄懂它的发动机 **FRI**，并且**在 mod-13 钟里亲手跑一个 mini-FRI**——包括一个会让你愣住的实验：一个偏离 1/4 的作弊者，在这个玩具规模下竟然能全身而退。看清"为什么玩具会输"，你就真正理解了"为什么真 FRI 要那么设计"。
> 前置：S02（钟表）、S03/S08（两种表身份、折叠）、S07（承诺要解决什么）。

## 1. 为什么需要第二条路

回顾 S07 的承诺 C = Σ fᵢ·Wᵢ：力量表 Wᵢ = τⁱ·G 来自一个**知道 τ 的仪式**。这带来三个包袱：

1. **信任假设**：仪式参与者至少一人诚实（"可信 setup"）；
2. **不抗量子**：配对/离散对数在量子计算下瓦解；
3. **域被绑架**：必须用配对友好的大素数域（BN254），享受不到小域（64-bit 级）的算术速度。

哈希路线的回答：**不用任何魔法对象，只靠"哈希 + 抽查"**。代价：证明更大、验证做哈希重算。它成立的核心是一个漂亮的代数事实——**"次数低" 在数据上表现为"聚集"**。

## 2. 发动机：Reed–Solomon 码视角

把多项式 f（次数 ≤ d）在域 D = {d₀,…,d_{N−1}} 上的取值表看成一个**码字**：全体"次数 ≤ d 的表"构成 N 维空间里的一个**低维子集**（只有 (d+1) 个自由度）。关键性质：

> **任意一张表，要么本身是低次多项式的表，要么与所有低次表的"距离"都很远**（至少 1 − (d+1)/N 的位置对不上）。

于是"证明次数低"可以改成"**证明这张表靠近码空间**"——而后者可以用**随机抽查**做：抽查一个位置抓不到（作弊者只改少量位置），但**抽查十几个位置全部命中的概率会指数塌掉**。FRI 的全部艺术在于：**不用读完表，就能验证"整张表离码空间很近"**。

## 3. FRI 机制：折叠 + 抽查

条件：域大小 N = 2^m，且 D 对"平方"封闭、对"取负"封闭（可取乘法子群）。协议两阶段：

- **折叠阶段**（m 轮）：P 发当前表的 Merkle 根；V 掷随机数 αᵢ；P 把表折半——对每个 y ∈ D²（原域的平方像）：

  ```
  f_{i+1}(y) = (1−αᵢ)/2 · [f_i(x) + f_i(−x)]  +  αᵢ/2 · [f_i(x) − f_i(−x)] / x      （x² = y）
  ```

  直觉：把 f 分解为偶部 A(X²) + 奇部 X·B(X²)——**次数每次减半**（f₁ 的次数 ≤ d/2）。α 的随机性保证：**如果 f 远离低次，那 f₁ 对绝大多数 α 也远离低次**（proximity gap，定量见文献 [BCIKS20]——本课标注边界，不深推）。
- **抽查阶段**：V 随机抽若干 x，要求 P 出示 f、f₁、f₂、… 沿链的对应值 + Merkle 路径，核对每一环的折叠等式。任何一环对不上即拒绝。

最终 P 交出**剩下的常数**（次数 < 1），V 核对它与最后一轮一致。

## 4. mod-13 玩具：全程手算

钟表世界 mod 13。取 4 阶乘法子群 **H = {1, 5, 8, 12}**（生成元 8：8⁰=1, 8¹=8, 8²=64≡12, 8³=5；对平方封闭：H² = {1, 12} ✓；对取负封闭：−1≡12、−5≡8 ✓）。

**被证对象**：表 = f(X) = **3X + 2** 在 H 上的取值（次数 ≤ 1）：

```
域序 (1, 5, 8, 12) → 表 [5, 4, 0, 12]        （f(5)=17≡4, f(8)=26≡0, f(12)=38≡12）
```

V 掷挑战 **α = 2**。折叠（对每个 x ∈ H，x² ∈ {1,12}；需要的逆元：1/2=7, 1/10=4, 1/3=9, 1/11=6）：

```
x=1:  偶部 (f(1)+f(−1))/2 = (5+12)/2 = 17×7 = 119 ≡ 2
      奇部 (f(1)−f(−1))/(2×1) = (5−12)/2 = (−7)×7 = 42 ≡ 3
      f₁(1²=1)  = 2 + 2×3 = 8
x=5:  偶部 (4+0)/2 = 2        奇部 (4−0)/10 = 4×4 = 16 ≡ 3
      f₁(5²=12) = 2 + 2×3 = 8
x=8 = −5:  与 x=5 平方同点 → 同样给 f₁(12) = 8 ✓（自洽）
x=12 = −1: 与 x=1 同点 → f₁(1) = 8 ✓
```

**诚实者的折叠表：f₁ = [8, 8]**（域 {1,12} 上）——**必然是常数**：f(X) = 3X+2 的偶部 A ≡ 2、奇部 B ≡ 3（都是常数），折叠后 f₁(Y) = A + α·B = 2 + 2×3 = **8，与 Y 无关** ✓。这就是"次数减半"在玩具上的样子：1 次 → 0 次。

**再折一次**：f₁ 是常数 → 偶部 8、奇部 0 → f₂ = 8 + α₂×0 = **8**（α₂ 是 V 第二轮掷的）。P 交出最终常数 **8**，V 核对一致。诚实者全程通过 ✓。

## 5. 亲眼看着玩具被攻破（本讲最重要的实验）

作弊表：**g = [5, 4, 0, 0]**——它在前 3 个点等于 3X+2 的真值、只在 x=12 处把 12 改成 0。它与"次数 ≤ 1"码的**距离 = 1/4**。

折叠（同样 α=2）：

```
x=1:  偶部 (5+0)/2 = 9        奇部 (5−0)/2 = 9        → g₁(1) = 9 + 2×9 = 27 ≡ 1
x=12: 偶部 (0+5)/2 = 9        奇部 (0−5)/24 = (−5)×6 = 9  → g₁(1) = 27 ≡ 1 ✓ 自洽
x=5:  偶部 (4+0)/2 = 2        奇部 (4−0)/10 = 3        → g₁(12) = 8
x=8:  同点自洽 ✓
作弊者折叠表：g₁ = [1, 8]（域 {1,12}）
```

**注意：四条折叠等式全部自洽**——作弊者可以交出 g₁ = [1,8] 并通过第一轮全部抽查（x=1 与 x=12 两个视角强迫同一个 g₁(1)=1，是这条偏离路径的巧合，也是玩具域太小的症状）。第二轮：g₂(1) = (1+8)/2 + α₂×(1−8)/2 = 11 + 3α₂——作弊者交出这个值，**依然自洽**。

**愣住之后想清楚三件事**（这就是真 FRI 与玩具的全部差距）：

1. **域太小**：|D| = 4 时，"距离码 1/4"的表只有 1 个坏点，而折叠把坏点与好点配对搅匀——4 条等式对 2 个未知数，自由度刚好够作弊。真 FRI 要求域远大于次数（安全参数级），此时"偏离 δ 的表"折叠后**对绝大多数 α 仍偏离 δ'**（proximity gap [BCIKS20]）——距离不消失；
2. **抽查次数**：真 FRI 每轮抽查 t 个位置，抓到概率 ≥ 偏离占比；多轮、多点连乘 → 逃逸 (1−δ)^t 指数塌缩。玩具 4 个点抽 1 个，抓到率只有 1/4；
3. **最终检查的实质**：真 FRI 的最后常数必须与**所有抽查链**一致且次数递减到底——作弊者要维持整条链，等价于让一张 δ-远的表在每轮折叠后仍然"看起来低次"——proximity gap 说这几乎不可能。玩具里它可能，因为一切数字都太小。

**教学结论**：mini-FRI 让你看清**机制**（折叠/抽查/一致性链）；**健全性的定量保证只在"域大小 ≫ 次数 × 安全参数"时成立**。这不是玩具的失败，而是它最重要的教学内容——大牛与新手之分，正在于知道每个机制在什么规模下才兑现它的承诺。

## 6. 从 FRI 到 BaseFold / WHIR / Binius（地图轴二的哈希族）

- **BaseFold**：把 FRI 的"域折叠"与**多线性折叠**（S08 §4 你手算过的那种）合流——折叠系数表的同时产生 FRI 层，承诺与打开一次完成。DeepProve 的透明 PCS 就是它（论文表 1/2 的 BaseFold 列）；
- **WHIR**（2024）：折叠 + 内嵌 sumcheck 的迭代版，当前哈希族多线性承诺的精度与效率标杆之一；
- **Binius**（2024）：直接在**二进制域塔** F₂ ⊂ F₄ ⊂ … 上工作——哈希和位运算免费、小域紧凑，专配"位运算重"的负载（哈希电路、VM）；
- **Circle STARK / M31**：用 Mersenne 素数 2³¹−1 与圆群替代乘法子群——CPU 友好的 31-bit 算术，Circle STARKs (2024) 解决了"域里没有 2^m 阶乘法子群"时的折叠问题。

**三族硬对比**（决策表，配 M01 的地图）：

| 维度 | KZG/HyperKZG | FRI/BaseFold/WHIR | IPA/Bulletproofs |
| --- | --- | --- | --- |
| setup | 毒物仪式 | **无** | 无 |
| 证明大小 | O(1)，最小 | O(log n)，较大 | O(log n)，中 |
| 验证 | 常数次配对（单次贵） | 哈希重算（可并行） | O(n) 线性（慢） |
| 抗量子 | ✗ | ✓ | ✓（基于离散对数假设的变体需注意） |
| 硬件友好 | MSM 专用 | 哈希流水线，GPU/ASIC 极佳 | 通用 |
| 域选择 | 被配对绑架 | **自由（小域红利）** | 通用 |

**DeepProve 的双 PCS 实验**（论文表 1/2 的机制解释）：HyperKZG 证明小一半（11.4 vs 24.3 MB）但长序列证明更慢（对 witness 承诺的开销随长度上升）；BaseFold 透明、大。**同一套 PIOP 跑两种 PCS** ——这正是 M01 §2"PIOP 与 PCS 解耦"的实盘验证。

## 7. 小域的工程现实（M03 的预告）

哈希族解锁了 64-bit/31-bit/二进制小域——算术快 3~10 倍、哈希免费。但小域带来三个新问题（M03 展开）：位宽不够表达计算 → **扩展域**；Montgomery/延迟约减的工程形态；FFT 的 2-adicity 要求（Goldilocks 2-adicity = 32、M31 用圆群、Binius 用塔）。
