# ZK 专家养成课程 · 总纲（v2.1）

> 本课程以 **deep-prove（DeepProve）** 这个生产级 zkML 系统为教学锚点，带你从零基础走到能设计、实现、审读多项式证明系统的水准。
> **v2 的由来**：v1 讲义被学员正确地批评为"名词堆叠、一句话讲完一个概念"。v2 的每讲只教一件事，按"**先动手做出来，再给名字**"的顺序展开，全程用一个可心算的小例子贯穿（13 格钟 + 4 格表），所有数字可复算、可对拍。

| --- | --- |
| 学员画像 | ZK 零基础（会基本代数；会 Rust 更佳，不会可边学边补） |

| 教材 | 基础篇 S01–S06 + 提高篇 S07–S10（本目录）+ 实战篇 L07–L09 + 仓库两份系统文档 + 精选论文 |
| 考核 | 12 个练习（P1~P12）+ 期末项目，验收标准见 L08 |

## 1. 教学法（本课程的五条铁律）

1. **一讲一件事**：一个概念独占一讲，讲不透不进入下一个；
2. **先做后名**：每个术语（MLE、eq、Fiat–Shamir、sumcheck、KZG、LogUp…）都在你亲手完成它的操作之后才出现——看到名词时你应该已经认识它做的事；
3. **单一贯穿例子**：全程一张 4 格表 `[3,1,2,0]` + 一个 13 格钟，每个数字可心算、可复核；提高篇把这条路线走到底：S06 悬空的主张被 S07 的指纹、S08 的收口逐步兑现；
4. **数字必须可复算**：讲义里每个数要么来自源码（标行号），要么给出推导；对不上就是讲义错了，报给导师；
5. **证明写全句子**：从 S02 的第一个证明起，训练"经得起挑字眼"的书面表达。

## 4. 毕业能力清单（可检验）

1. **理论**：白板证明 sumcheck 完备性/健全性；推导 KZG 承诺/打开/验证；推导 LogUp 恒等式；讲清 batched sumcheck 收口恒等式（S08 §2 的 eq 项由 V 自算）；
2. **系统**：画出 DeepProve 端到端数据流（trace → MLE → 承诺 → claim 链 → 收口 → 合并验证），每步指到 `文件:行号`；
3. **代码**：读懂 `prove_chunk` 与 `verify_streaming` 每一行；独立实现 toy sumcheck / KZG / LogUp（各 < 300 行）；跑通 GPT-2 端到端并剖析耗时；
4. **工程**：dump 对拍工具；为新算子设计并接入 PIOP（期末项目）；
5. **研究**：读协议论文（Gemini §2.4.2 或 LogUp）并写综述。

## 5. 与导师的互动

- **作业**：交 `homework/sNN/` 或 `homework/weekNN/`，导师逐题批改（手算题必须列中间数字，证明题写全句子）；
- **答疑**：卡点直接问，导师按"直觉 → 推导 → 代码"三层回答；**任何名词若没被"先做后名"地介绍过就出现，视为讲义 bug，直接投诉**；
- **检查点**：W3（S06 白板重跑）、W6（三点恒等式推导复述）、W12（毕业答辩）；
- **讲义维护**：以源码为准，发现冲突回报导师更新。
