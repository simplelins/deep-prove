# ZK 专家养成课程 · 总纲

> 本课程以 **deep-prove（DeepProve）** 这个生产级 zkML 系统为教学锚点，带你从零基础走到能设计、实现、审读多项式证明系统的水准。
> 所有理论都以"能在本仓库代码里指到对应实现"为落脚点——这是本课程与任何公开课的最大差别：你学的每一个协议，都有一份真实的、可运行、可修改的工业实现作为练习场。

| 项目 | 内容 |
| --- | --- |
| 学员画像 | ZK 入门者（懂基本代数、会 Rust 更佳，不会也可边学边补） |
| 课程周期 | 12 周，每周 10~15 小时 |
| 教材 | 本目录 9 份讲义（L01~L09）+ 仓库内 2 份系统文档（见下）+ 精选论文 |
| 考核 | 12 个练习（P1~P12）+ 期末项目，验收标准见 L08 |
| 目录 | `docs/zk_course/`（本课程）；`docs/zkml_bootcamp/`（系统文档） |

## 1. 教材体系与阅读关系

```
理论主线（本课程讲义）                      系统精读（仓库已有文档）
L01 数学基础 ─┐
L02 sumcheck ─┼─→ L06 zkML与DeepProve ─→ prove_chunk_原理与实现详解.md   ←—— 系统主教材
L03 GKR     ─┤                          prove_pipeline_FPGA算子开发指导.md ←—— 算子级参考手册
L04 承诺方案 ─┤
L05 查表论证 ─┘   L07 代码精读 → L08 练习与项目 → L09 进阶前沿
```

- **讲义（L01~L05）**：协议本身——定义、推导、健全性证明、数值例子、代码落点。每讲末有自测题与作业。
- **系统主教材**：`prove_chunk_原理与实现详解.md`（协议在 DeepProve 里的完整落地，全部结论经过源码逐行核实）与 `prove_pipeline_FPGA算子开发指导.md`（14 个算子的规格书，兼作"每个算子的协议作用"速查）。
- **论文**：只安排 4 篇必读精读 + 若干选读，清单在 L09 附录，全部给到"标题 + 出处"，可检索获取。

## 2. 毕业能力清单（可检验）

完成课程后你应当能够：

1. **理论**：白板证明 sumcheck 的完备性与健全性；解释 Schwartz-Zippel 引理如何支撑一切；推导 KZG 的承诺/打开/验证等式；推导 LogUp 的对数导数恒等式；说明 batched sumcheck 把 k 条 claim 归到单点的原理。
2. **系统**：画出 DeepProve 一次证明的端到端数据流（trace → MLE → 承诺 → claim 链 → batched sumcheck → RLC → HyperKZG 打开 → 合并验证），并把每一步指到 `文件:行号`。
3. **代码**：读懂 `prove_chunk` 与 `Verifier::verify_streaming` 的每一行；能实现 toy sumcheck / toy KZG / toy LogUp（每个 < 300 行 Rust）；能跑通 GPT-2 端到端证明并剖析耗时分布。
4. **工程**：为一个新的模型算子设计 PIOP 并接入本系统（期末项目）；用 dump 工具做 CPU golden 对拍。
5. **研究**：读完一篇协议论文（如 Gemini §2.4.2 或 LogUp），写出内容、创新点与工程影响的综述。

每一项能力都对应明确的练习与验收标准（L08）。

## 4. 学习方法（导师要求）

1. **推导优先**：每个协议先不看代码、不看资料，自己推一遍"为什么这样构造、为什么安全"，再对照讲义修正。证明系统的学习成本全部在"为什么"上。
2. **例子驱动**：每讲的可验算小例子必须手工算一遍。算得动 2×2 的例子，才算真懂。
3. **代码即真理**：任何与讲义冲突的实现细节，以代码为准，并回报给导师更新讲义。
4. **输出倒逼输入**：每周写一页"本周我给别人讲明白了什么"。讲不清楚 = 没学会。
5. **不追求一遍读懂**：sumcheck 与承诺方案建议各学两遍（第一遍协议、第二遍工程优化）。

## 5. 与导师的互动方式

- **批改**：每周作业放到 `homework/weekNN/`，向导师提出批改请求；导师逐题给反馈与补充推导。
- **答疑**：任何卡点直接提问，导师按"先 intuition、再推导、最后代码"三层回答。
- **进度检查**：第 4/8/12 周各有一次口头检查（导师随机抽讲义中的证明让你白板复述）。
- **毕业答辩**：30 分钟——20 分钟讲你选定的协议/项目，10 分钟答辩；通过标准见 L08 §考核。

## 6. 本课程与公开课程的关系

本课程不替代系统学习材料，而是**以工业实现为锚的重构**：Thaler 的书仍是理论权威（必读章节在周计划中标出），Vitalik 的博客是快速直觉来源，论文是第一手资料。本讲义的价值在于：把"教科书协议"与"这份代码怎么写的"之间的沟壑填平——所有 `文件:行号` 都可点开验证。
