# ZK 专家养成课程 · 总纲（v2.2 · 合卷版）

> 本课程以 **deep-prove（DeepProve）** 这个生产级 zkML 系统为教学锚点，带你从零基础走到能设计、实现、审读多项式证明系统的水准。
> **教学法五条铁律**：①一讲一件事；②先动手做出来，再给名字；③全程一个可心算的贯穿例（13 格钟 + 4 格表）；④每个数字可复算（源码行号或推导）；⑤证明写全句子。任何名词若未按此介绍就出现 = 讲义 bug，直接投诉。

| 项目 | 内容 |
| --- | --- |
| 学员画像 | ZK 零基础（会基本代数；会 Rust 更佳，不会可边学边补） |
| 课程周期 | 第一学期 12 周（W1–W12）+ 大师阶段 12 周（W13–W24） |
| 目录 | 本目录（课程四卷 + 总纲）；`docs/zkml_bootcamp/`（系统文档与论文）；`homework/`（作业） |

## 4. 毕业能力清单（可检验）

1. **理论**：白板证明 sumcheck 完备性/健全性；推导 KZG 承诺/打开/验证；推导 LogUp 恒等式；讲清 batched sumcheck 收口恒等式；
2. **系统**：画出 DeepProve 端到端数据流，每步指到 `文件:行号`；
3. **代码**：读懂 `prove_chunk` 与 `verify_streaming` 每一行；独立实现 toy sumcheck / KZG / LogUp；跑通 GPT-2 端到端并剖析耗时；
4. **工程**：dump 对拍工具；为新算子设计并接入 PIOP；
5. **研究**：读协议论文并写综述。

## 5. 与导师的互动

- 作业交 `homework/`，导师逐题批改（手算题列中间数字，证明题写全句子）；
- 卡点按"直觉 → 推导 → 代码"三层答疑；**任何名词若未按"先做后名"介绍就出现 = 讲义 bug，直接投诉**；
- 检查点：W3（S06 白板重跑）、W6（三点恒等式推导）、W12、W24（大答辩）；
- 以源码为准：讲义与代码冲突时报导师修讲义。
